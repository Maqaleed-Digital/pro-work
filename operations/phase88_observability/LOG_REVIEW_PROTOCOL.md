# LOG REVIEW PROTOCOL

## Services
- web-service
- api-service

## Review Targets
- uncaught errors
- 5xx responses
- startup failures
- repeated warnings
- latency anomalies

## Review Window
- last 1 hour for live verification
- last 24 hours for early operations review

## Output
Evidence files must include command outputs for:
- service logs query
- error filter query
- recent request sample
