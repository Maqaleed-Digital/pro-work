# ProWork UI Implementation Wave 1

This is a stack-neutral UI implementation bundle for:

- app shell + navigation rebuild
- design system implementation
- executive control tower
- playbooks / AI / trust surfaces
- productized landing and vertical pages
- tenant onboarding and sales demo flows

## Files
- index.html                  -> productized landing
- control-tower.html          -> executive control tower
- operations.html             -> workflows, playbooks, AI operators, trust
- verticals.html              -> consulting / fintech / industrial packaging
- onboarding.html             -> tenant onboarding demo flow
- styles.css                  -> design system + layout + states
- app.js                      -> navigation helpers + demo interactions

## Local preview
Open any HTML file directly in browser, or use a simple local server.

Example:
python3 -m http.server 8080

Then visit:
http://localhost:8080/ui_wave1/index.html
