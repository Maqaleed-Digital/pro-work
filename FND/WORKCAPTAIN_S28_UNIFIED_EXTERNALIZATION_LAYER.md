# WORKCAPTAIN — S28 UNIFIED EXTERNALIZATION LAYER

Version: 1.0  
Status: LOCKED FOR EXECUTION  
Baseline Commit: f7194b6  
Applies From: Sprint S28  

---

## 1. PURPOSE

S28 closes all remaining P0 platform gaps in one governed execution layer.

This sprint converts WorkCaptain from an internally operational system into an externally visible, enterprise-sellable platform.

S28 is not a new architecture sprint.  
S28 is the productization and externalization sprint.

---

## 2. S28 TARGET STATE

At S28 closure, WorkCaptain must present one unified operational surface exposing the already-built execution, trust, compliance, and evidence capabilities.

The platform must become:

- visible
- explorable
- usable
- explainable
- auditable
- enterprise-demoable

---

## 3. P0 GAP CLOSURE SCOPE

### 3.1 Command Center
Deliver a CEO / operator decision surface with:

- KPI strip
- risk strip
- AI signal strip
- sovereign compliance strip
- evidence / trust strip
- quick actions
- route-level navigation into execution domains

### 3.2 AI Control Surface
Deliver a visible AI governance workspace with:

- recommendation log
- rationale / confidence / signal basis
- human approve / reject actions
- override capture

- immutable audit references

Deliver KSA sovereign visibility with:

- Nitaqat impact visibility
- WPS readiness visibility
- probation timeline visibility
- compliance status widgets
- alerts and deadline surfacing
- PDPL-aware controls

### 3.4 Trust & Evidence Surface
Deliver an enterprise audit workspace with:

- evidence pack index
- evidence pack viewer
- audit trail timeline
- ZIP / PDF export initiation
- AI artifact visibility
- approval chain visibility

### 3.5 Payments & Escrow Surface
Deliver financial visibility with:

- escrow state visibility
- fee disclosure visibility
- dispute / hold visibility
- payout status visibility
- release timing visibility

### 3.6 PDPL Readiness Layer
Deliver privacy-operational capability with:

- DSR request visibility
- export / deletion workflow entry points
- redaction control visibility
- cross-border handling controls
- consent state visibility

### 3.7 Externalization Foundations
Deliver minimum enterprise-ready exposure with:

- route completeness
- role-aware navigation
- tenant-safe access patterns
- API readiness contract
- public/private boundary clarity

## 4. S28 NON-NEGOTIABLE RULES

1. Do not redesign the core architecture.
2. Do not bypass evidence creation.
3. Do not auto-close gates using AI.
4. Do not ship hidden AI actions without visible approval paths.
5. Do not ship sovereign claims without visible UI surfaces.
6. Do not ship evidence generation without evidence retrieval visibility.
7. Do not regress S25/S26/S27 runtime loops.
