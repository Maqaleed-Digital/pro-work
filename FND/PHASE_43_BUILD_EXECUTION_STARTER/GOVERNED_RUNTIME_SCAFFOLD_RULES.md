# GOVERNED RUNTIME SCAFFOLD RULES

## Purpose

This document defines the rules that the starter code scaffold must obey.

## Runtime Principle

Even the first scaffold must preserve institutional runtime discipline.

## Scaffold Rules

The starter scaffold must preserve:

1. route-to-domain traceability
2. object-to-contract traceability
3. role-aware surface separation
4. invalidity-aware placeholders
5. escalation-safe extension points
6. audit and event extension readiness
7. shared contract reuse

## Prohibited Drift

The scaffold must not:

- collapse all domains into one module
- create stateful UI actions without contract intent
- expose raw mutation surfaces without future authorization slots
- omit invalidity or escalation placeholders for governed objects

## Outcome

These rules keep the initial codebase aligned with the institutional system from day one.
