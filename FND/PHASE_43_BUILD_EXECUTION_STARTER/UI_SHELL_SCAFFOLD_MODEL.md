# UI SHELL SCAFFOLD MODEL

## Purpose

This document defines the governed UI shell scaffold for WorkCaptain / ProWork.

## Shell Principle

The UI shell must express institutional navigation and role-bounded product structure from the first executable build wave.

## Required Shell Elements

The scaffold must establish:

1. root application shell
2. governed navigation spine
3. placeholder route surfaces for each top-level domain
4. role-sensitive navigation handling
5. invalidity-aware state slots
6. escalation and status banner zones

## Required Route Surfaces

The starter shell must include routes for:

- command center
- board and assurance
- pipeline and intake
- allocation and resilience
- federation and entities
- accountability and recovery
- doctrine and certification

## Shell Rule

The starter shell must remain structurally complete even when downstream business logic is still stubbed.

## Outcome

The UI shell scaffold gives the institutional system its first navigable runtime surface.
