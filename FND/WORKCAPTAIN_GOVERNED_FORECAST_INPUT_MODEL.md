# WORKCAPTAIN / PROWORK — GOVERNED FORECAST INPUT MODEL

Version: 1.0
Status: ACTIVE

## Forecast Inputs

Each active deal forecast input must include:

- deal_id
- current_stage
- owner
- expected_decision_window
- forecast_band
- confidence_state
- artifact_basis
- key_risk_summary
- key_blockage_summary
- next_action

## Rule

Forecast inputs are controlled estimates only and may not be represented as commitments.
