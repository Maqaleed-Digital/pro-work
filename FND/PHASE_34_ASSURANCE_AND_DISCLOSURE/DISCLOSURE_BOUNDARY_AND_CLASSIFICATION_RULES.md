# DISCLOSURE BOUNDARY AND CLASSIFICATION RULES

## Purpose

This document defines the disclosure boundaries and classification rules that govern all external assurance outputs.

## Classification Levels

### Level 1 — Internal restricted
Not eligible for external disclosure.
Used for board-only, executive-only, or structurally sensitive material.

### Level 2 — Controlled institutional
Eligible for limited external disclosure under approved audience and purpose constraints.

### Level 3 — Confidence-safe external
Eligible for structured investor or partner disclosure when backed by validated evidence and bounded narrative rules.

## Boundary Rules

A disclosure item must not cross classification level without:

- source validation
- boundary reclassification approval
- audience fit confirmation
- governance non-conflict check

## Non-Disclosure Conditions

An item must remain undisclosed if any of the following apply:

- evidence is incomplete
- governance validity is unresolved
- allocation posture is sensitive
- reserve posture is sensitive
- escalation remains open
- disclosure would create misleading confidence

## Classification Outputs

Each disclosure item must produce:

- classification level
- audience eligibility
- disclosure conditions
- exclusion status
- review requirement

## Strategic Rule

Disclosure confidence must never exceed operating truth.
