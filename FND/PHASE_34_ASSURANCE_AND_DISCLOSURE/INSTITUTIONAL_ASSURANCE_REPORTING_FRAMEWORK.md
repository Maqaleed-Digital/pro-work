# INSTITUTIONAL ASSURANCE REPORTING FRAMEWORK

## Purpose

This document defines the institutional assurance reporting framework for WorkCaptain / ProWork.

The framework governs how the system produces board-grade, investor-grade, and partner-grade assurance views while preserving evidence integrity, governance discipline, and disclosure boundaries.

Assurance reporting is not presentation formatting.
It is a governed reporting layer that converts validated system state into confidence-grade institutional reporting.

## Framework Principle

Assurance outputs must not be narrative-led.

Each reporting output must be derived from:

- validated evidence lineage
- active governance constraints
- allocation-valid institutional posture
- scenario and reserve-valid resilience posture
- disclosure classification rules
- escalation and exception status
- traceable source state

## Mandatory Assurance Views

The framework must support at minimum:

1. Board assurance view
2. Investor assurance view
3. Strategic partner assurance view
4. Institutional governance status view
5. Portfolio confidence view

## Reporting Outputs

Each assurance report must produce:

- reporting scope
- reporting audience classification
- evidence-backed state summary
- governance posture summary
- allocation posture summary
- resilience posture summary
- disclosure boundary status
- escalation or exception flags
- reporting validity status

## Validity Rule

If Phase 26 evidence validity fails, all assurance outputs are invalid.

If Phase 31 governance validity fails, all assurance outputs are invalid.

If Phase 32 allocation validity fails, all assurance outputs are invalid.

If Phase 33 scenario or reserve validity fails, all assurance outputs are invalid.

Assurance reporting is downstream of evidence validity, institutional governance, allocation discipline, and resilience discipline.
