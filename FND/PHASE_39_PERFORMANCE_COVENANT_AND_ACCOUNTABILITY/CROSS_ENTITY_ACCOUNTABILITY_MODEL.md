# CROSS-ENTITY ACCOUNTABILITY MODEL

## Purpose

This document defines how accountability is assigned, recognized, and enforced across entities in the federated portfolio.

## Accountability Principle

Accountability must be traceable, non-transferable by convenience, and compatible with shared doctrine.

Cross-entity accountability exists when local actions affect:

- shared validity
- shared confidence
- shared allocation posture
- shared resilience posture
- sovereign credibility
- portfolio-wide command coherence

## Accountability Domains

The model must support accountability across:

1. truth and evidence integrity
2. governance compliance
3. strategic synchronization compliance
4. intervention and escalation responsiveness
5. disclosure and engagement conduct
6. recovery and remediation execution

## Accountability Outputs

Each accountability record must define:

- accountable entity
- affected shared control layer
- issue class
- impact radius
- escalation level
- remediation owner
- closure condition

## Accountability Rule

An entity cannot externalize responsibility for a shared-control breach merely because the originating issue was local.

## Outcome

The accountability model makes cross-entity responsibility explicit and enforceable.
