# PERFORMANCE BREACH ESCALATION RULES

## Purpose

This document defines how performance breaches are escalated when covenant obligations are not met.

## Breach Principle

A breach is not merely missed output.
A breach occurs when performance degradation threatens institutional validity, doctrine compatibility, portfolio coherence, or external confidence.

## Breach Classes

### Class A — Local performance breach
Contained within local scope and not yet threatening shared validity.

### Class B — Shared portfolio performance breach
Affects more than one entity or degrades shared portfolio command quality.

### Class C — Institutional doctrine breach
Threatens shared doctrine, confidence architecture, sovereign credibility, or board-governed posture.

## Escalation Levels

### Level 1 — Local correction review
For contained issues inside local authority limits.

### Level 2 — Shared command escalation
For breaches affecting shared portfolio posture or synchronized execution.

### Level 3 — Executive and board enforcement escalation
For breaches affecting doctrine, sovereign sensitivity, confidence, or institutional legitimacy.

## Breach Outputs

Each breach record must produce:

- breach class
- source entity
- affected obligation
- escalation level
- intervention requirement
- remediation deadline basis
- closure status

## Fail-Closed Rule

No breach may be treated as closed while shared control damage or doctrine conflict remains unresolved.
