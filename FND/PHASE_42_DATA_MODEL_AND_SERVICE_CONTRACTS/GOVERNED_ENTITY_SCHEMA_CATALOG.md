# GOVERNED ENTITY SCHEMA CATALOG

## Purpose

This document defines the schema catalog for the governed objects identified in the institutional operating model.

## Schema Principle

A schema is not only storage structure.
It is a governed institutional contract.

Schemas must preserve:

- object identity
- lifecycle state
- actor ownership
- authority compatibility
- traceability
- invalidity recognition
- event compatibility

## Required Schema Domains

The schema catalog must define at minimum:

### 1. Entity schema
For local and federated operating entities.

### 2. Opportunity and deal schema
For pipeline, activation, and command-affecting commercial objects.

### 3. Intake schema
For qualified entry, source classification, and routing.

### 4. Allocation schema
For capital, priority, and intervention-affecting decisions.

### 5. Scenario and reserve schema
For resilience, reserve usage, and contingency posture.

### 6. Escalation and intervention schema
For command-sensitive or accountability-sensitive actions.

### 7. Assurance and certification schema
For bounded assurance, readiness, closure, and trust-seal states.

### 8. Accountability and remediation schema
For covenant breaches, recovery cycles, and sanctions.

## Schema Outputs

Each schema definition must include:

- primary key model
- core required fields
- optional fields
- lifecycle status field
- actor / owner reference
- evidence reference fields
- invalidity / block flags
- auditability requirements

## Schema Rule

No implementation schema may omit lifecycle, ownership, or invalidity structure for a governed object.

## Outcome

The schema catalog becomes the implementation reference for database and contract modeling.
