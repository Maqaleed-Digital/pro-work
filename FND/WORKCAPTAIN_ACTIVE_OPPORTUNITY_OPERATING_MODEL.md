# WORKCAPTAIN / PROWORK — ACTIVE OPPORTUNITY OPERATING MODEL

Version: 1.0
Status: ACTIVE

## Purpose

Define how active opportunities are managed once qualified and activated.

## Operating Rules

- each active opportunity has one accountable owner
- each active opportunity has one current stage
- each active opportunity has one next action
- all outward statements must remain bounded
- every material interaction must be traceable
- escalation occurs before ambiguity becomes commitment

## Required States

- active
- paused
- escalated
- decision_pending
- closed_won
- closed_lost
- parked
