# BOARD OPERATING CADENCE

## Cadence Structure

Monthly:
- Portfolio review
- Revenue performance
- Risk exposure review

Quarterly:
- Strategic alignment
- Capital allocation
- Portfolio restructuring

Ad-hoc:
- Critical escalation
- Risk breach response

## Decision Windows

- Monthly board review window (fixed)
- Emergency override window (on escalation)

## Inputs

- Phase 30 executive dashboard
- Evidence-linked deal states
- Portfolio dependency model

## Outputs

- Board decisions (binding)
- Intervention directives
- Governance constraints
