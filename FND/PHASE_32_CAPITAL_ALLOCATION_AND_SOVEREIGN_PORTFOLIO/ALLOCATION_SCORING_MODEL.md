# ALLOCATION SCORING MODEL

## Purpose

This scoring model standardizes how allocation decisions are ranked and approved.

The model converts institutional judgment into a governed decision structure.

## Scoring Dimensions

Each allocation candidate must be scored across the following dimensions:

### 1. Revenue potential score
Measures expected contribution to portfolio revenue quality and realization.

### 2. Conversion confidence score
Measures validated likelihood of conversion using evidence-backed pipeline state.

### 3. Sovereign alignment score
Measures alignment with KSA, GCC, sovereign-tech, workforce modernization, compliance, public-private, or national-priority value creation.

### 4. Portfolio resilience score
Measures whether the allocation improves diversification, resilience, and strategic balance.

### 5. Dependency reduction score
Measures whether the allocation reduces over-reliance on a narrow set of deals, sectors, or actors.

### 6. Institutional priority score
Measures board-level or executive-command relevance to institutional direction.

### 7. Intervention urgency score
Measures urgency of executive or board intervention required to preserve or unlock value.

## Scoring Bands

- 90–100 = Priority Alpha
- 75–89 = Priority Beta
- 60–74 = Priority Controlled
- 40–59 = Watchlist
- Below 40 = Non-priority / do not allocate without board exception

## Minimum Decision Rule

No capital allocation recommendation is valid without:

- completed dimension scoring
- evidence-backed rationale
- concentration impact check
- dependency impact check
- governance constraint validation

## Negative Override Rule

A candidate must not be prioritized, regardless of score, if any of the following are unresolved:

- invalid evidence lineage
- governance breach
- unresolved concentration breach
- unresolved dependency escalation
- sovereign conflict condition
- board constraint conflict

## Output Structure

Each scored record must produce:

- candidate name
- candidate type
- allocation class
- total score
- dimension breakdown
- recommended action
- board escalation flag
- reallocation impact note
