# INTERVENTION AND REALLOCATION PROTOCOL

## Purpose

This protocol defines when the institution must reallocate capital, operating capacity, or executive attention across the portfolio.

## Reallocation Triggers

Mandatory reallocation review is triggered by any of the following:

- concentration breach
- dependency breach
- conversion collapse
- evidence invalidation
- governance conflict
- sovereign priority shift
- executive intervention failure
- board directive change

## Intervention Levels

### Level 1 — Executive adjustment
Used for controlled tuning inside existing governance boundaries.

### Level 2 — Executive reallocation
Used when material capacity or portfolio attention must be shifted.

### Level 3 — Board escalation
Used when reallocation affects institutional posture, strategic balance, or capital governance.

## Mandatory Reallocation Rule

If a Tier 1 allocation loses evidence validity, governance validity, or resilience logic, reallocation review is immediate and mandatory.

## Protocol Outputs

The protocol must produce:

- trigger identified
- level assigned
- impacted portfolio elements
- reallocation candidates
- expected resilience effect
- expected revenue effect
- board escalation requirement
- closure record
