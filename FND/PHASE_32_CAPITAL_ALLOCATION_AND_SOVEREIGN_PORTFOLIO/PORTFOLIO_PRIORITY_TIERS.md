# PORTFOLIO PRIORITY TIERS

## Purpose

This document defines the institutional priority tiers used by the allocation engine.

## Tier Structure

### Tier 1 — Strategic Core

These are portfolio priorities that directly support institutional direction, executive command objectives, and board-level confidence.

Characteristics:
- high conversion relevance
- high institutional value
- strong evidence base
- board-compatible priority
- positive resilience effect

### Tier 2 — Structured Expansion

These are controlled expansion opportunities that support growth while preserving governance discipline.

Characteristics:
- moderate to strong evidence
- controlled exposure
- positive strategic adjacency
- manageable dependency profile

### Tier 3 — Controlled Optionality

These are options worth preserving but not yet ready for primary allocation intensity.

Characteristics:
- partial readiness
- emerging evidence
- uncertain conversion path
- low immediate board urgency

### Tier 4 — Observation Only

These remain visible but should not attract material capital or executive attention without requalification.

Characteristics:
- weak evidence
- low readiness
- unclear fit
- unclear resilience contribution

## Re-tiering Rule

Any portfolio item can move between tiers only when supported by:

- updated evidence state
- changed conversion profile
- changed dependency profile
- changed sovereign relevance
- changed board or governance directive

## Tier Enforcement

Tiering must influence:

- capital allocation
- executive time allocation
- escalation thresholds
- intervention frequency
- reporting prominence
