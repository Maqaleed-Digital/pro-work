# CAPITAL ALLOCATION ENGINE

## Purpose

This document defines the institutional capital allocation engine for WorkCaptain / ProWork.

The engine governs how portfolio attention, strategic capital, operating capacity, and executive intervention are allocated across opportunities, programs, and sovereign tracks.

This is not a finance spreadsheet layer.
This is an institutional execution allocation layer.

## Allocation Domains

The allocation engine governs four allocation domains:

1. Strategic capital allocation
2. Executive attention allocation
3. Operating capacity allocation
4. Sovereign priority allocation

Each domain must remain evidence-based, board-governed, and fail-closed.

## Allocation Principle

Capital allocation must not be based on narrative preference.

Allocation must be derived from:

- validated pipeline state
- evidence-backed revenue potential
- concentration and dependency exposure
- sovereign priority alignment
- portfolio resilience profile
- intervention requirement level

## Core Allocation Rule

No material allocation decision is valid unless supported by:

- validated evidence path
- board-governed constraints
- institutional scoring model
- traceable rationale
- timestamped decision record

## Allocation Decision Classes

### Class A — Core portfolio reinforcement

Used when an opportunity or track is already validated and requires reinforcement to accelerate conversion, revenue realization, or portfolio resilience.

### Class B — Strategic expansion allocation

Used when the portfolio is extending into adjacent or new high-priority execution spaces with justified evidence and institutional sponsorship.

### Class C — Sovereign positioning allocation

Used when allocation supports KSA, GCC, sovereign-tech, labor-market, regulatory, or national-priority positioning.

### Class D — Protective reallocation

Used when portfolio concentration, exposure, or execution blockage requires immediate reallocation to preserve institutional outcomes.

## Allocation Outputs

The engine must produce the following outputs:

- allocation class
- allocation rationale
- allocation priority score
- dependency impact view
- concentration effect view
- risk-adjusted allocation decision
- intervention requirement status
- board escalation requirement
- reallocation candidate mapping

## Allocation Validity Rule

If Phase 26 evidence validity is broken, all allocation outputs are invalid.

If Phase 31 governance constraints are missing, all allocation outputs are invalid.

The allocation engine is downstream of both evidence validity and institutional governance.
