# WORKCAPTAIN / PROWORK — PORTFOLIO CONVERSION GOVERNANCE MODEL

Version: 1.0
Status: ACTIVE

## Purpose

Define how active opportunities are governed as a conversion portfolio rather than isolated deals.

## Governance Rules

- every deal remains owner-assigned
- every deal remains stage-bound
- conversion priority must be explicit
- portfolio balance must be reviewed
- concentration and dependency must be visible
- intervention must be recorded

## Rule

No portfolio conversion posture may be declared without deal-level evidence basis.
