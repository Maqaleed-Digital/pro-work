# INSTITUTIONAL INHERITANCE RULES

## Purpose

This document defines what any new entity must inherit in order to qualify as a valid extension of the WorkCaptain / ProWork institutional system.

## Inheritance Principle

Institutional inheritance is not branding inheritance.
It is operating doctrine inheritance.

## Mandatory Inheritance Elements

Every valid inherited entity must inherit:

1. source-of-truth discipline
2. evidence lineage obligations
3. governance and invalidity rules
4. allocation and exposure discipline
5. resilience and reserve discipline where applicable
6. disclosure and engagement discipline
7. sovereign doctrine compatibility
8. continuity and succession obligations

## Inheritance Validity Rule

If any mandatory inheritance element is missing, the entity is not institutionally inherited and must not be represented as such.

## Inheritance Outputs

Each inherited entity must define:

- inherited control layers
- local deviations if any
- approved adaptation scope
- invalidity triggers
- escalation linkage
- continuity obligations

## Outcome

Inheritance rules make expansion verifiable, rather than rhetorical.
