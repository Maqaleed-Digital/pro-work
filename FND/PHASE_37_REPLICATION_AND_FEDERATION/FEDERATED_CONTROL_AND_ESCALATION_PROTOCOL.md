# FEDERATED CONTROL AND ESCALATION PROTOCOL

## Purpose

This document defines how control and escalation operate across multiple entities in the federated portfolio.

## Protocol Principle

Federation requires escalation discipline, not only local autonomy.

Cross-entity issues must be escalated when they affect:

- shared validity
- capital exposure
- disclosure posture
- sovereign sensitivity
- portfolio resilience
- doctrine integrity

## Escalation Levels

### Level 1 — Local entity review
Used when the issue remains contained within approved local authority.

### Level 2 — Shared portfolio review
Used when the issue affects more than one entity or shared portfolio posture.

### Level 3 — Institutional board escalation
Used when the issue affects doctrine integrity, sovereign posture, capital exposure, or institution-wide confidence.

## Protocol Outputs

Each federated escalation must produce:

- source entity
- issue classification
- impacted control layer
- escalation level
- affected shared constraint
- resolution status
- closure record

## Fail-Closed Rule

No federated issue may be treated as resolved while shared doctrine or shared validity remains compromised.

## Outcome

The protocol ensures portfolio federation scales without losing institutional control.
