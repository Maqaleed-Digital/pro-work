# WORKCAPTAIN REAL-WORLD TRUTH MODEL

## Hard Rule
The system accepts facts, not intentions.

## Allowed Inputs
- measured values
- actual project availability
- actual governance decisions
- actual approval records
- actual evidence files

## Disallowed Inputs
- placeholders
- estimated paths
- verbal assumptions
- implied approvals
- uplift values without supporting evidence

## Final Rule
If the repository does not contain the evidence and the approval, the truth has not yet been provided to the system.
