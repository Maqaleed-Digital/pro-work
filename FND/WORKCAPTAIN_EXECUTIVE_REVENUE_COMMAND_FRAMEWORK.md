# WORKCAPTAIN / PROWORK — EXECUTIVE REVENUE COMMAND FRAMEWORK

Version: 1.0
Status: ACTIVE

## Purpose

Define the executive command layer for governed revenue oversight and portfolio intervention.

## Framework Principles

- executive visibility without boundary bypass
- owner accountability preserved
- explicit stage and forecast posture
- intervention only with evidence basis
- concentration awareness
- escalation before unsupported certainty

## Rule

No executive command action may proceed without owner, stage, portfolio context, and next action.
