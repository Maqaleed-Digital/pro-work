# PORTFOLIO-WIDE COMMAND VISIBILITY RULES

## Purpose

This document defines how command visibility is structured across the federated institutional portfolio.

## Visibility Principle

Visibility must be sufficient for portfolio command, but bounded by valid authority and classification rules.

Not all information is globally visible by default.
Visibility must remain:

- role-appropriate
- entity-appropriate
- doctrine-compatible
- escalation-compatible
- classification-safe

## Visibility Layers

### Layer 1 — Local entity command visibility
Local command view for entity-specific operation and bounded authority.

### Layer 2 — Shared portfolio visibility
Cross-entity visibility for portfolio coordination, dependency recognition, and intervention prioritization.

### Layer 3 — Executive and board command visibility
Institution-wide view for strategic command, exposure management, and federated governance.

## Visibility Rules

Portfolio-wide visibility must define:

- what is visible
- to whom
- for what purpose
- under what classification rules
- under what escalation conditions

## Visibility Rule

No portfolio command visibility is valid if it exceeds authority scope, breaches classification boundaries, or obscures invalidity conditions.

## Outcome

Visibility rules make portfolio command possible without degrading discipline or disclosure boundaries.
