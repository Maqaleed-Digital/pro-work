# INSTITUTIONAL PORTFOLIO COMMAND NETWORK

## Purpose

This document defines the institutional portfolio command network for WorkCaptain / ProWork.

The command network governs how multiple entities are viewed, coordinated, prioritized, and directed as one federated institutional portfolio without weakening local control boundaries or shared doctrine.

The command network is not a dashboard concept.
It is a governed command structure.

## Command Principle

Portfolio-wide command must preserve both:

- shared institutional doctrine
- bounded local execution autonomy

The command network must unify visibility and synchronization without collapsing federation discipline.

## Command Network Requirements

The command network must preserve:

1. shared truth visibility
2. cross-entity strategic coherence
3. portfolio-wide intervention prioritization
4. board-compatible control escalation
5. common invalidity recognition
6. sovereign-compatible operating alignment
7. traceable command decisions

## Command Outputs

Each portfolio command state must produce:

- entity command status
- portfolio priority view
- synchronization status
- shared risk and escalation view
- intervention priority map
- board relevance status
- command validity state

## Command Rule

No portfolio-wide command directive is valid if it bypasses inherited doctrine, local authority boundaries, or shared invalidity rules.

## Outcome

The institutional portfolio command network establishes the standing command layer across the federated portfolio.
