# COMMAND NETWORK INVALIDITY AND ESCALATION RULES

## Purpose

This document defines invalidity and escalation rules for the institutional portfolio command network.

## Invalidity Principle

The command network must recognize invalidity early and escalate before shared doctrine, confidence, or portfolio coherence degrades.

## Mandatory Invalidity Triggers

The command network must treat the following as invalidating conditions:

1. shared truth integrity breach
2. cross-entity governance inconsistency
3. doctrine conflict between entities
4. classification or disclosure conflict
5. unresolved shared escalation
6. portfolio command visibility distortion
7. cross-entity sovereign credibility conflict

## Escalation Levels

### Level 1 — Shared portfolio command review
Used when the issue affects portfolio command but remains below institution-wide doctrine threat.

### Level 2 — Executive command escalation
Used when federation-wide synchronization, intervention, or alignment is materially affected.

### Level 3 — Board command escalation
Used when doctrine integrity, sovereign posture, confidence architecture, or portfolio-wide legitimacy is at risk.

## Fail-Closed Rule

No command state may be treated as valid while mandatory invalidity triggers remain unresolved.

## Outcome

Invalidity and escalation rules ensure the command network scales only through governed coherence.
