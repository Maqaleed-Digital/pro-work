# FEDERATION-WIDE INTERVENTION PRIORITY MODEL

## Purpose

This document defines how interventions are prioritized across the federated institutional portfolio.

## Priority Principle

Intervention priority must be determined at the portfolio level when issues affect:

- shared validity
- doctrine integrity
- capital exposure
- resilience posture
- sovereign-sensitive credibility
- cross-entity strategic alignment

## Priority Classes

### Priority Alpha
Immediate portfolio-level intervention required.

### Priority Beta
Material intervention required with shared coordination.

### Priority Controlled
Intervention required but may remain within managed entity or shared portfolio cycle.

### Priority Watch
Visible for command monitoring but not yet requiring portfolio intervention.

## Priority Outputs

Each intervention candidate must define:

- source entity
- issue class
- control layer impacted
- federation-wide relevance
- escalation level
- required coordinating authority
- closure condition

## Priority Rule

Local urgency does not automatically equal portfolio urgency, but shared doctrine or shared validity breaches always elevate priority.

## Outcome

The intervention priority model allows the federation to direct attention where institutional risk or opportunity is greatest.
