# WORKCAPTAIN / PROWORK — COMMERCIAL EXECUTION COCKPIT FRAMEWORK

Version: 1.0
Status: ACTIVE

## Purpose

Define the commercial cockpit that governs active opportunities across investor, enterprise, and sovereign pursuits.

## Cockpit Principles

- one active opportunity view
- explicit ownership
- explicit stage control
- artifact-backed execution
- health and momentum visibility
- escalation before unsupported commitment

## Required Cockpit Fields

- opportunity_id
- pursuit_category
- owner
- stage
- next_action
- artifact_basis
- health_state
- momentum_state
- escalation_state
- outcome_state

## Rule

No opportunity may remain active without owner, stage, and next action.
