# WORKCAPTAIN — PHASE 8 EVIDENCE AND RUNBOOK

Version: 1.0  
Status: ACTIVE

## 1. Required Evidence

Evidence pack must include:

- uptime check creation output
- alert policy creation output
- service describe snapshots for all four services
- monitoring inventory snapshots
- manifest with timestamp and source-of-truth commit

## 2. Runbook Minimum

Runbook note should record:

- what is being monitored
- what alerts now exist
- which endpoint is considered public liveness signal
- where to inspect Cloud Run service state
- where to inspect alert policies and uptime checks

## 3. Failure Rule

If monitoring artifacts are not created, this phase is not complete.
