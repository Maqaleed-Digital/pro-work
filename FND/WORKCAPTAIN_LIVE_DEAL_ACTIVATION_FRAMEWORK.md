# WORKCAPTAIN / PROWORK — LIVE DEAL ACTIVATION FRAMEWORK

Version: 1.0
Status: ACTIVE

## Purpose

Define how live opportunities are activated in a governed manner after presentation and diligence readiness.

## Activation Rules

- every opportunity must have a named owner
- every opportunity must have a pursuit category
- every opportunity must begin with an explicit identified record
- activation requires qualification completion
- activation must reference approved assurance artifacts
- all stage movements must be recorded

## Core Pursuit Types

- investor
- enterprise
- sovereign_strategic

## Rule

No live activation occurs without qualification and boundary confirmation.
