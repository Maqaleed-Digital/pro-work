# WORKCAPTAIN / PROWORK — ENTERPRISE CLIENT ASSURANCE PROFILE

Version: 1.0
Status: ACTIVE

## Purpose

State the enterprise assurance posture of WorkCaptain / ProWork for client diligence and controlled onboarding discussions.

## Assurance Claims

- governed execution paths
- role and permission control
- approval-bound privileged actions
- append-only evidence discipline
- audit export capability
- tenant and jurisdiction isolation
- fail-closed governance posture
- continuous control attestation
- compliance reporting support

## Boundary

This profile is an assurance posture statement derived from internal governance artifacts and evidence.
It is not a substitute for client-specific legal, security, or procurement review.

## Intended Uses

- client diligence
- enterprise onboarding discussion
- internal sales enablement for governed deployments
- compliance-oriented platform positioning
