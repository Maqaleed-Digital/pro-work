# CONTINGENCY RESPONSE PLAYBOOK

## Purpose

This playbook defines the institutional response posture when downside, stress, or sovereign shift scenarios require coordinated action.

## Contingency Classes

### Class A — Revenue protection
Used when portfolio revenue quality or conversion realization is deteriorating.

### Class B — Resilience protection
Used when concentration, dependency, or structural fragility threatens institutional balance.

### Class C — Sovereign response
Used when sovereign-aligned openings or shifts require disciplined response.

### Class D — Governance stabilization
Used when evidence, escalation, or intervention structures are under strain.

## Response Elements

Each contingency response must define:

- scenario class
- trigger condition
- immediate operating response
- allocation adjustment requirement
- reserve deployment review
- escalation path
- board notification requirement
- closure criteria

## Strategic Rule

Contingency response must preserve institutional discipline.

No response may bypass evidence, governance, allocation, or board constraints.
