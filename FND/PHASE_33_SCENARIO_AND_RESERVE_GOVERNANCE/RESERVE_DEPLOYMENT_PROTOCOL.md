# RESERVE DEPLOYMENT PROTOCOL

## Purpose

This protocol defines when and how strategic reserves may be deployed.

## Deployment Triggers

Reserve deployment review is triggered by any of the following:

- downside deterioration
- concentration breach
- dependency breach
- portfolio stress condition
- sovereign acceleration window
- board-directed strategic intervention
- resilience protection requirement

## Deployment Levels

### Level 1 — Executive reserve adjustment
Controlled usage within existing executive authority and board constraints.

### Level 2 — Material reserve deployment
Material deployment affecting allocation, capacity, or institutional posture.

### Level 3 — Board reserve authorization
Required when reserve usage changes strategic balance, sovereign posture, or resilience baseline.

## Protocol Outputs

Each deployment review must produce:

- trigger identified
- reserve category
- deployment level
- expected resilience effect
- expected revenue effect
- expected portfolio effect
- authority basis
- escalation requirement
- closure record

## Fail-Closed Rule

No reserve deployment is valid if:

- evidence lineage is invalid
- governance constraints are unresolved
- scenario state is undefined
- authority basis is unclear
