Applies From Commit: 256f238f0a3cc3df00baa67ff2847d3d4b0eb6ce

## 1. Purpose

This phase establishes the executive revenue command layer and portfolio conversion governance system for WorkCaptain / ProWork.

The objective is to elevate the Phase 29 revenue operations layer into an executive command model that supports:

- executive pipeline oversight
- portfolio-level conversion governance
- decision-priority visibility
- concentration and dependency awareness
- controlled conversion planning
- escalation-aware executive intervention

## 2. Outcomes

Phase 30 must establish:

- executive revenue command framework
- portfolio conversion governance model
- executive command dashboard model
- conversion stage governance model
- portfolio concentration and dependency model
- executive review and intervention cadence
- portfolio evidence discipline
- executive conversion decision workflow

## 3. Preconditions

Phase 30 may proceed only if all of the following are true:

- source-of-truth commit matches approved baseline
- Phase 29 evidence directory exists
- Phase 29 core artifacts exist
- strict Phase 26 evidence validation rule exists
- no critical prerequisite artifact is missing

## 4. Operating Boundary

Phase 30 authorizes executive revenue command and portfolio conversion governance only within the existing certified, assurance-bounded, and commercially governed posture.

Phase 30 does not authorize:

- unsupported revenue claims
- unsupported conversion certainty claims
- unsupported regulatory or legal claims
- third-party certification claims unless separately obtained
- executive override of evidence, stage, or boundary discipline

The executive layer must provide a governed command view where the active commercial portfolio is:

- stage-visible
- owner-accountable
- concentration-aware
- conversion-governed
- evidence-backed
- intervention-ready
- boundary-controlled

- portfolio_segment

- dependency_state
- conversion_priority
