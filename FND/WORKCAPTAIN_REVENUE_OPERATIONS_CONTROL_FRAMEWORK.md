# WORKCAPTAIN / PROWORK — REVENUE OPERATIONS CONTROL FRAMEWORK

Version: 1.0
Status: ACTIVE

## Purpose

Define the governed revenue operations layer for active deals and pipeline execution.

## Framework Principles

- owner accountability
- explicit stage control
- bounded forecasting posture
- evidence-backed dashboard state
- escalation before unsupported certainty
- regular review cadence

## Rule

No active revenue operation may proceed without owner, stage, forecast posture, and next action.
