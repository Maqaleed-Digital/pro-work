# UI-01 — INFORMATION ARCHITECTURE + NAVIGATION RESET

## OBJECTIVE
Restructure the platform interface around its true operating model: control tower, workflows, playbooks, AI operators, trust, tenants, revenue, and governance.

## TARGET OUTCOME
Move from fragmented feature navigation to executive-grade operating navigation.

## NAVIGATION PRINCIPLES
- one executive home
- one clear workflow home
- one trust home
- one revenue home
- no duplicate menu labels
- no buried control surfaces
- role-aware visibility only

## UX RULES
- reduce lateral menu clutter
- make critical actions reachable in one or two steps
- preserve tenant-safe scoping
- preserve audit surface visibility
